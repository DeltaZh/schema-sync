# DDL 投放策略可配置

日期：2026-08-19  
状态：已实现

## 目标

1. `CREATE TABLE`（含 `IF NOT EXISTS`）默认按**常规**放行。  
2. 语句类型策略可在「设置」页配置：常规 / 高风险 / 不允许。  
3. `DROP DATABASE` / `DROP SCHEMA` 默认为不允许，但允许用户改为高风险或常规。

## 范围

- 仅影响「DDL 投放」预览/执行校验与二次确认。  
- 基准同步仍用差异项 `dangerous` 标记。

## 数据

`config.json` 增加 `ddl_policy`（缺省时用内置默认）。固定语句类型枚举，未识别类型一律不允许。

## UI

顶栏新增「设置」页签：表格配置各类型档位；保存 / 恢复默认。

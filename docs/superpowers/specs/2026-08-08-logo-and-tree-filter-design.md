# Logo 与库表即时筛选

日期：2026-08-08  
状态：已批准（会话确认）

## 目标

1. 替换默认 Tauri/Vite 图标为「数据库 + 双向同步箭头」专业工具感 logo。
2. 连接树与「选择可见库」支持 DataGrip 式随输入筛选。

## Logo

- 风格：深蓝圆柱数据库 + 双向箭头，扁平、浅底可读。
- 落地：`public/app-icon.png` / favicon、`index.html`、`src-tauri/icons/*`（经 `tauri icon` 生成）。
- 侧栏顶部展示小图标 + 友好产品名「结构同步」。

## 搜索行为

### 连接树

- 工具栏下全局搜索框，占位「筛选库 / 表…」。
- 不区分大小写，子串匹配。
- 命中连接名：保留该连接，其下库表再按规则筛。
- 命中库名：显示该库（表列表仍随展开状态）。
- 命中表名：显示所属库，并只列出命中表。
- 无结果提示「没有符合的库或表」；清空恢复全树。

### 选择可见库

- 列表上方搜索框，占位「筛选库名…」。
- 仅过滤展示；勾选状态不丢。
- 「全选」作用于当前筛出结果。

## 非范围

- 本轮不改基准同步下拉选库搜索。
- 不新增后端接口，纯前端过滤。

# 库名模板规则

日期：2026-08-08  
状态：已批准（会话确认：模板用于拼库名）

## 模型

| 字段 | 含义 |
|---|---|
| display_name | 列表显示名，可自定义 |
| pattern | 库名模板，如 `order_{年份}_{租户}`；连接符写在模板内 |
| tenants / years / shards | 占位符取值列表 |
| connection_ids | 绑定连接 |

占位符：`{年份}` `{租户}` `{分片}`（兼英语 `year` / `tenant` / `shard`）。

## 兼容

旧配置仅有 `logical_name` + `parts_order` 时，加载/保存时推导为  
`{logical_name}_{年份}_…`（按原顺序，固定 `_`），`display_name` 默认等于模板。

## UI

- 左侧列表：主行显示名，副行模板  
- 编辑：显示名、库名模板、按模板用到的取值列表、绑定连接
